# Güncelleme (giriş ekranı + ayarlar + API)
1. Bu zip'i açın. İçindeki RimsaApi ve RimsaTerminalAndroid klasörlerini GitHub deponuza (test) ana dizine sürükleyip bırakın.
   (Aynı dosyalar üzerine yazılır.) "Commit changes" deyin.
2. .github/workflows/api.yml dosyasını sohbette verilen metinle Add file > Create new file ile ekleyin.
3. Actions: "APK olustur" yeni APK'yı, "API olustur" sunucu programını üretir.
4. API kurulumu için RimsaApi/KURULUM_API.md dosyasını okuyun.
